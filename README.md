- Retrofit + OkHttp + Coroutines
- NestJS + TypeScript
- PostgreSQL
- Next.js + TypeScript
- REST + OpenAPI
- Docker/VPS-ready
- myQuran API v3 + EQuran API v2 via server-side provider gateway
