# Screen Specification v1.0

Main TV priorities: current time → current/next prayer → prayer schedule → countdown → mosque identity → content.

States: BOOT, PAIRING, NORMAL, PRE_ADZAN, ADZAN, IQOMAH, PRAYER_MODE, CONTENT, EVENT, OFFLINE, ERROR/FALLBACK.

Operational indicators: SYNCING, SYNC_FAILED, STALE_DATA, PRAYER_PROVIDER_UNAVAILABLE, FALLBACK_CALCULATION.

Responsive layout must adapt without clipping/distortion and respect safe area/overscan.
